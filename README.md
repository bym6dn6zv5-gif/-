# 具身智能学习课程

面向车辆工程本科生，从编程起步，围绕轮式机器人的感知、规划、控制与系统交付逐步学习。

目标是在导师或工程师指导下，能够完成小模块开发、实验或缺陷修复，为机器人软件、仿真评测及相关算法实习作准备。

## 时间安排

80个学习周，每周约8小时，核心内容约640小时；另留80至160小时用于环境配置、补课与项目修改。考虑考试和假期，常规周期约24个月。

“学习周”是进度单位，可以放慢。专业课优先；考试周减量或暂停推进。每课按“一个核心概念 → 具体例子 → 独立练习 → 提交批改”进行，模块通过后再继续。

## 如何记录作业

提交时写明：课号、自己的代码或推导、实际输出、预期输出，以及遇到的问题。程序报错时保留完整报错和复现步骤；没有完成也可以记录卡点。

初始状态为 **L001待开始**。每周记录当前课号、实际用时、独立完成部分、卡点和下一次任务。详细评分与模块验收见完整课程。

## 项目主线

P0练习表达计算，P1分析运动数据，P2建立运动模型与控制，P3接通导航系统，P4训练并评估学习策略，P5整合为可交付系统。

真机阶段优先使用校内既有低速平台。缺少设备时可以完成接口模拟和回放，真机验收保留待完成；仿真结果与真实运行经历分别记录。课程完成情况通过实际作品和独立任务验证，不等同于企业录用结果。
