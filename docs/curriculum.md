# 具身智能学习课程

车辆工程本科生的80周课表 实践作业与第一课

版本 1.0    2026年10月24日    零基础起步    常规学习周期约24个月

本课程以轮式机器人的感知、规划与控制为主线，从独立编程走向机器人学习和系统交付。目标是在导师或工程师指导下，能够完成一个小模块、一次实验或一个缺陷修复，为机器人软件、仿真评测及相关算法实习作准备。

### 这份课程包含什么

80个学习周，共160个课次、80次周实践和12个模块验收。课次包括基础讲解、实验讲评和项目研讨；每周表中列明两次课的主题、实践成果和检查方式。文末提供完整第一课与未附答案的练习，其余课次按学习进度逐课展开。

学习周指完成一周内容的进度单位，并非必须连续的自然周。80周核心内容按每周8小时约为640小时；另留约80至160小时用于环境配置、补课和综合项目返工。两年约104个自然周，余下时间供考试、假期和缓冲。首次安装与排障也计入时间。

### 学习方式与进阶原则

每课先讲一个概念，再看一个车辆或机器人例子，随后独立练习，提交后批改。概念解释、环境配置可以充分使用AI；关键编程与调试能力需要无完整答案的变式验证。每个模块通过后再推进依赖它的内容。

本课程沿用先前方案的主线，并放慢最初四周的语法节奏。前沿大模型、复杂足式控制和高阶强化学习留作基础达标后的专修，具体方向在完成导航项目后选择。

前期使用现有电脑。真机模块优先依托校内团队；没有设备时完成接口模拟与记录回放，继续推进软件和仿真成果，真机验收保持待完成。涉及实机部署的岗位必须补齐相应经历，简历明确区分仿真与真实运行。

## L001 把任务拆成明确步骤

建议用时40至60分钟。今天只学习一个核心概念：把一个模糊要求写成明确、按顺序可执行的步骤。本课可以先在纸上完成，不要求安装软件，也不假定你懂代码。

### 为什么机器人需要明确步骤

“让小车开得好一点”没有说明目标，也无法检查是否做到。换成“小车以给定的恒定速度行驶给定时间，算出路程”，任务就具体了：需要哪些已知量，怎样处理，最后给出什么，都可以说清楚。

程序是一组由计算机执行的指令。写程序之前，你可以先用普通中文把步骤讲明白。后面的Python学习，就是逐渐把这些步骤表达成计算机能执行的形式。复杂程序以后可以包含判断、重复和同时进行的任务；今天先掌握顺序步骤。

### 一个完整例子

任务：一辆教学小车匀速行驶，速度为8米每秒，持续4秒。忽略加速和减速，计算这段时间的路程。这里讨论的是理想化计算，不是在控制真实车辆。

| 部分 | 本例中的内容 |
| --- | --- |
| 输入 | 速度8米每秒；时间4秒 |
| 处理 | 用速度乘以时间，即8乘4 |
| 输出 | 路程32米 |

对应步骤：先读取速度，再读取时间，然后相乘，最后把数值和单位一起展示。输入中的速度或时间变了，处理方法仍然适用。因此，这是一种可重复使用的方法。

### 最容易忽略的地方

第一，单位要一致。速度是千米每小时时，不能直接和秒相乘就写成米。第二，任务假设要明确；速度不断变化时，今天的简单计算方法需要调整。第三，结果要能检查；只显示一个没有单位的数字，还没有把任务说明完整。

### 你的练习 先不看答案

- 练习1：小车匀速行驶，速度为6米每秒，时间为7秒。分别写出输入、处理、输出，并用中文列出执行步骤。

- 练习2：把要求改为“已知路程和恒定速度，计算需要的时间”。只写步骤，不需要编程。指出哪个输入不能为零。

- 练习3：有人输入“速度36千米每小时，时间10秒”，直接相乘并把结果写成米。说明问题出现在哪里，以及应先补上哪一步。

### 提交与通过标准

按“练习1／练习2／练习3”提交你的文字或纸面作答即可。通过标准是输入完整、步骤可执行、单位明确，并能指出明显无效输入。批改时先判断你的思路，再给必要提示；下一课才开始运行第一段程序。

| --- | --- | --- |
| 导航与控制 | 12至16周，状态估计、约束优化、LQR与MPC | 有模型误差分析和实机证据的控制改进 |
| 机器人学习 | 16至24周，数据收集、序列策略、强化学习与迁移 | 一个严格评测的操作或导航学习项目 |
| 机器人系统 | 12至16周，C++并发、通信、性能与部署 | 能定位瓶颈且可维护的系统模块 |

专修是完成基础后的备选，课时为学习预算。先依据项目兴趣、目标岗位和团队资源选定一条，再制定详细课次。保持专业课成绩与实际项目积累，两者共同支持后续实习和升学。
