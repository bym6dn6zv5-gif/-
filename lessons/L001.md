# L001 把任务拆成明确步骤

建议用时40至60分钟。今天只学习一个核心概念：把一个模糊要求写成明确、按顺序可执行的步骤。本课可以先在纸上完成，不要求安装软件，也不假定你懂代码。

## 为什么机器人需要明确步骤

“让小车开得好一点”没有说明目标，也无法检查是否做到。换成“小车以给定的恒定速度行驶给定时间，算出路程”，任务就具体了：需要哪些已知量，怎样处理，最后给出什么，都可以说清楚。

程序是一组由计算机执行的指令。写程序之前，你可以先用普通中文把步骤讲明白。后面的Python学习，就是逐渐把这些步骤表达成计算机能执行的形式。复杂程序以后可以包含判断、重复和同时进行的任务；今天先掌握顺序步骤。

## 一个完整例子

任务：一辆教学小车匀速行驶，速度为8米每秒，持续4秒。忽略加速和减速，计算这段时间的路程。这里讨论的是理想化计算，不是在控制真实车辆。

| 部分 | 本例中的内容 |
| --- | --- |
| 输入 | 速度8米每秒；时间4秒 |
| 处理 | 用速度乘以时间，即8乘4 |
| 输出 | 路程32米 |

对应步骤：先读取速度，再读取时间，然后相乘，最后把数值和单位一起展示。输入中的速度或时间变了，处理方法仍然适用。因此，这是一种可重复使用的方法。

## 最容易忽略的地方

第一，单位要一致。速度是千米每小时时，不能直接和秒相乘就写成米。第二，任务假设要明确；速度不断变化时，今天的简单计算方法需要调整。第三，结果要能检查；只显示一个没有单位的数字，还没有把任务说明完整。

## 你的练习 先不看答案

- 练习1：小车匀速行驶，速度为6米每秒，时间为7秒。分别写出输入、处理、输出，并用中文列出执行步骤。

- 练习2：把要求改为“已知路程和恒定速度，计算需要的时间”。只写步骤，不需要编程。指出哪个输入不能为零。

- 练习3：有人输入“速度36千米每小时，时间10秒”，直接相乘并把结果写成米。说明问题出现在哪里，以及应先补上哪一步。

## 提交与通过标准

按“练习1／练习2／练习3”提交你的文字或纸面作答即可。通过标准是输入完整、步骤可执行、单位明确，并能指出明显无效输入。批改时先判断你的思路，再给必要提示；下一课才开始运行第一段程序。
